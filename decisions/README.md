# decisions/ — 架构决策记录（ADR）

记录所有技术选型与架构决策的**完整决策路径**（背景 → 备选 → 取舍 → 结论），
供不熟悉本技术栈的维护者（人类与 AI）追溯"当时为什么这么定"。

## 规则
- 文件名：`NNN-短横线标题.md`，编号只增不减
- 触发条件：引入新依赖/新模块、跨模块设计变更、验证策略变更、任何"为什么不用 X 而用 Y"的选择
- 状态：`proposed → accepted`（可 `superseded by NNN` 被取代）
- 由 sdd-plan（提出）与 sdd-review（定稿归档）维护；**没有 ADR 的实质选型视为流程违规**
